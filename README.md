# 红军长征 · 交互式历史地图（网页版）

以红军长征为主题的交互式历史地图网页：在腾讯地图（合规底图，自带审图号）上标注**主要行军路线、关键战役、重要会议、出发地与终点**，共 45 个历史事件节点；支持点击标记查看详情、时间轴分阶段展示、按部队筛选、3D 俯视视角切换；**路线时间轴动画演示**（播放/暂停/快进/重置/进度条拖拽）；桌面与移动端自适应。

## 路线动画演示

- 以 1934.10 — 1936.10 全局时间轴驱动四路红军路线**逐段生长**：播到遵义会议时刻，路线正好画到遵义；播到会宁/将台堡时刻，三大主力会师
- 到达关键节点自动**点亮标记**并弹出该事件的历史说明（详情面板 + 地图平滑跟随）
- 控件：播放/暂停、快进（1× / 2× / 4× 循环）、重置；**进度条可拖拽**定位任意时刻（进度条带阶段刻度与 21 个关键事件金点，悬停查看名称与日期）；键盘 <kbd>空格</kbd> 播放/暂停、<kbd>R</kbd> 重置
- 部队筛选**动画中与平时均生效**：多支部队同时播放即可对比各部队行军路径；播放中改变筛选会自动重置动画
- 实现：事件日期解析为时间锚点 → 投影到行军路径弧长 → 时间→(段, 段内比例) 分段线性曲线；跨阶段/无数据区间（如红二方面军 1934.10—1935.11 空档）自动转为等待期，不会画出假连线

## 本地查看

方式一（推荐）：在 WorkBuddy 中直接预览 `dist/index.html`——腾讯地图 SDK 走内置密钥代理，**零配置**。

方式二：本地静态服务器（SDK 需要 http 环境，不能直接双击 file:// 打开）：

```bash
node tools/serve.js 8723
# 浏览器访问 http://127.0.0.1:8723/
```

> 注意：方式二中若不配置自有 Key，底图瓦片将无法加载（页面会给出降级提示，界面框架仍可用）。要走通方式二，请按下一节配置 Key。

## 部署

`dist/index.html` 是自包含单文件（除腾讯地图 CDN 外无任何外部依赖），可原样放到任意静态托管（GitHub Pages / nginx / OSS / Vercel 等）。

### 切换到自有 Key（在 WorkBuddy 预览之外的环境必需）

默认模板使用 WorkBuddy 运行时托管的密钥代理（占位符 `__WB_HTTP_PORT__` / `__WB_TMAP_SECRET__` 由运行时自动替换）。独立部署时：

1. 到[腾讯位置服务开放平台](https://lbs.qq.com/)申请 JavaScript API GL 的 Key（免费）；
2. 编辑 `src/index.template.html`：删掉 `window._TMapSecurityConfig = {...}` 整段，SDK 地址改为 `https://map.qq.com/api/gljs?v=1.exp&key=你的KEY`；
3. `node build.js` 重新打包。

安全提示：前端 Key 明文可被抓取，个人使用请在控制台配置 Referer 白名单；商业用途建议由后端代理 Key 请求。

## 自定义内容

所有史实内容集中在 `src/data.js`：

- `EVENTS`：事件（名称/日期/部队/阶段/分类/坐标/说明/要点）——动画引擎据 `date` 字段自动生成时间轴，改日期即改动画节奏
- `PHASES`：七个阶段（名称/时间/概述）
- `ROUTES`：按阶段 + 部队组织的路线分段（`[经度, 纬度]`）——动画按段顺序投影锚点，新增路线段会自动纳入播放
- `ARMIES` / `CATEGORIES`：部队配色、标记分类与图标
- 坐标为 WGS-84 近似值，渲染时自动转 GCJ-02 与底图对齐

动画参数在 `src/anim.js` 顶部：`DURATION_MS`（1× 全程时长，默认 90 秒）、`SPEEDS`（倍速序列）。

改完后：

```bash
node tools/validate.js   # 校验数据完整性
node build.js            # 重新打包 dist/index.html
```

## 字体与响应式排版

字号体系统一由 `src/style.css` 的 `:root` 令牌驱动，**任何视口下层级比例一致、无第二套硬编码**：

- **字号阶梯**（语义化令牌，全部 `clamp(最小, 流式, 最大)`）：`--fs-display`（顶栏主标题）→ `--fs-h1`（事件标题）→ `--fs-h2`（面板标题）→ `--fs-h3`（小节标题）→ `--fs-lead`（概述）→ `--fs-body`（正文）→ `--fs-btn`（按钮）→ `--fs-chip`（筛选）→ `--fs-sm`（辅助）→ `--fs-xs`（最小可读级）；`--lh-body` 行高同步流式（小屏收紧、大屏舒展）
- **流式区间**：320px 小屏（下限兜底，最小可读级 ≥11px）→ 4K 大屏（上限封顶，不松散）；断点（860 / 520 / 380 / 1600）只调布局、间距与次要信息显隐，不再覆盖字号
- **画布文字**（地图 MultiLabel 标注，JS 像素值不受 CSS 管控）：`src/app.js` 按视口断点补偿基准字号（≤520 +2、≤860 +1.5、≥1600 +0.5），初始构建即生效，`resize` 跨断点 150ms 去抖重建（同断点不重建）
- 改字号只改 `:root` 一处，全局生效

## 合规说明

- 底图为腾讯地图（矢量底图，审图号数据），国界、台湾、南海诸岛等领土要素由其合规数据呈现，本页不手绘任何边界；
- 页面不嵌入任何密钥（默认代理模式）；
- 坐标系为 GCJ-02；
- 事件坐标为示意近似值，路线为示意连线，页面已内嵌声明，仅供历史文化学习参考，不作为导航或任何法定用途依据。

## 已知限制

- 原生地图组件无法按 DEM 高程把山体"拔高"为真三维地形；"立体感"由 3D 俯视视角（pitch 0–45）提供。如需真实地形起伏需接入高程数据自绘 WebGL，是另一个量级的工程。
- 事件坐标为记忆近似值，上架前建议按权威史料二次校准。
- `mapStyleId`（个性化底图样式）需在腾讯位置服务控制台单独激活，默认 Key 不可用，故未使用。
